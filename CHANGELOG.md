# Changelog

## Unreleased

- **Cicero 0.1.11.** The pin moves from Cicero 0.1.10, under which a paragraph cut at a hyphen the browser drew (`hyphens: auto`) was refused by Caster: the first piece's last word read `conse‐`, matched no run of its source, and 749 characters of the Quiet Press counted as presented on no page (Cicero's Codeberg issue 14). 0.1.8 carries the fault; 0.1.11 writes the hyphen as an engine text node before a break mark.
- **A refused print leaves no file.** `beltype print` removes the output as the run starts, so a print that refuses no longer leaves an earlier PDF at that path to stand for it. Proved by `test/small-rows.test.ts`.
- **`beltype print` says the standard its file claims.** The summary line ends with Caster's claim, `pdf-2.0; pdf-ua-2` or `pdf-2.0`, as `beltype serve` already sends it in `x-beltype-standard`; `print()` returns it as `standard`. Under `--printer chromium` Caster never saw the file and the line says nothing. Proved by `test/small-rows.test.ts`.
- **A symlink cannot pull a file from outside the document's folder.** The folder test was lexical while the file test followed links, so a link inside the folder served what it pointed at. Both sides are now resolved to where they land, and a link that stays inside still serves. Proved by `test/small-rows.test.ts`.
- **The kept page's stale font is Chromium's, not Caster's** (`serve-font-cached-by-url`, still a todo). Measured in a bare Playwright page: a font under one URL, then `document.open()` and other bytes under that URL, measures the first font's width again, with `cache-control: no-store`, `Network.setCacheDisabled` or `Network.clearBrowserCache`; a second page of the same context, or a new URL, measures the new bytes. The kept-page test's todo says so now instead of blaming Caster. No code fix: the only one is a new page for every document that declares a font, which is a ruling.
- **The CLI is a binary, not a module.** The README says so: no `exports` map and no typings until a consumer asks.

## 0.1.8 — 2026-11-08

- **Cicero 0.1.10, Caster 0.2.5 and specimens 0.1.1.** The pins move from Cicero 0.1.6, Caster 0.1.7 and specimens 0.1.0. Caster 0.2.5 prints a kept page's second cut as its first: under Cicero 0.1.10 a mail merge whose data changed nothing printed the `provvedimento-imu`'s footer with one frozen page number on every page. Caster's report carries `confessions`, so `--check` now excuses the tiles a confession covers; the mail-merge tests over `bolletta` and `provvedimento-imu` read specimens 0.1.1. What each release changed is in its own CHANGELOG.
- **`--check` fails the run; `--check=report` keeps the report alone.** Ruled 2026-11-08. A page whose share of differing pixels crosses 3.5 %, whose worst 24 px tile crosses 40 %, or a page count that differs between screen and print makes `beltype print --check` exit 1 after the report, one line a failing page naming its share or its tile and its `diff-N.png`; `check.json` gains `maxShare`, and a page its `pass`, its worst `tile` and its `kind`. Both were measured on Caster's corpus (sixteen documents, 37 pages). The share: median 0.73 %, highest text page 1.76 %, set about twice that; a page drawn blank reads 5 %. The tile, which S91's acceptance suite reads beside the share: highest clean text page 19.6 %, highest clean picture page 17.7 %, so both floors are 40 %, and S91's 120 by 30 px block covers at least 62.5 % of some tile wherever it falls; five picture pages read 44 to 100 %, each a real disagreement (`blackText: 100k`, a CMYK JPEG's band, a JPEG the browser cannot decode, a shadow drawn as a raster, a blend), and those fail. The wording narrows: the check compares the PDF with the pages Cicero presented in the same run, the proof that the printer drew what the engine cut.
- **`--check` excuses a tile the printer confessed.** Ruled 2026-11-08. A tile over its floor passes where Caster's report confessed a region over it (`confessions`, Caster's S90 as amended 2026-11-08): each region, grown by the one pixel of slip, covers the screenshot's pixels, and a tile is excused when what differs outside every cover, counted against what lies outside, is at or under the floor; a tile wholly inside is excused, one straddling an edge only when its outside part would pass alone. The page's line names the confession, `check.json` carries the excused tiles with their kind and element and the confessions read, and the share is never excused. Against Caster's `fix/report-confesses-where`, linked: roads, images and arithmetic pass with their tiles excused by `black-text`, `cmyk-image` and `undecodable-image`, and vector-roads' page 2 has 28 tiles excused by `opacity` and `blend` but fails on its CMYK shading at (552, 96), 89 %, which nothing confesses. S91's block painted outside every region still fails.
- **`--check` aligns a bled page on its trim.** Caster grows the media round the presented page for a bleed and print marks and writes no `/TrimBox`; the page stays at the PDF's origin, so the printed raster is cropped there to the screenshot's size before the diff. Caster's `roads` read 25.7 % and 17.8 % from the corner and 2.3 % and 13.0 % aligned.
- **`beltype serve --allowed-hosts <name[:port],…>`, and a wildcard bind needs it.** Bound to `0.0.0.0` or `::`, the server cannot know the name it is reached by, and held only the `Origin`, which leaves DNS rebinding open: a page's own name, resolved to this machine, arrives with its own `Host` and its own `Origin`. A wildcard bind now answers only the hosts on the list, refusing any other with `403` before the body is read, and without a list it refuses to start, naming the flag. A name with no port is that name on any port. On a loopback bind the list is accepted and not needed. The testbench's `beltype-serve` passes `--allowed-hosts beltype-serve:3000`.
- **`beltype serve` says what the file claims.** A PDF answer carries `x-beltype-standard`, read from Caster's report of the print: `pdf-2.0; pdf-ua-2` where the file claims PDF/UA-2, and `pdf-2.0` alone under `caster.standard=none` or where Caster guessed a tag for an element it could not name and withdrew the claim. A caller no longer has to open the file's XMP to know. A print under `beltype.printer=chromium` is Chromium's own file, which Caster never saw, and carries no header.
- **The README blamed the wrong package for the running head.** "3. Results" from `content()` alone is Caster's: its preparation turns the heading's `::before` into a real span before Cicero cuts, and `content()` then reads it. The README said Cicero.
- **`beltype serve` answers only its own name and no other origin.** A request whose `Host` is not the address it is bound to, or that carries an `Origin` of another page, is refused with `403` before its body is read: a form needs no preflight, so any page open in your browser could otherwise post a document to a running server. Bound to `0.0.0.0` or `::`, the server cannot know the name it is reached by, and holds the `Origin` alone.
- **An `on…=` attribute with no space before it no longer takes the kept page.** `<svg/onload=…>`, `<img src=x"onerror=…>` and `<svg><set/onbegin=…>` now send a document to a page of its own, and a template that holds one is refused.
- **Chromium runs in its sandbox.** `beltype print` and `beltype serve` launch with the sandbox; `--no-sandbox` launches without it, for a container that runs as root, where Chromium will not start in it.
- **A print that times out leaves nothing behind.** Its page is closed and its folder removed before the `504`, and what it asked for afterwards never lands in the next print's refusal: each print keeps its own list of what it could not be given.

- **`beltype serve` takes a mail merge as data** (codeberg.org/BelType/cli issue 2). `POST /templates` takes the template once, and `POST /templates/<id>/print` takes one customer's values and rows as JSON. The tab merges with `prosemirror-stores`, bundled in `assets/merge/` so an install fetches nothing from git, and replaces only the top-level boxes that changed, on the same page. On the `bolletta` each PDF is byte for byte the one `/print` makes of the same merged document, in any order of customers; on the `provvedimento-imu` each copy matches its article in `batch.html` pixel for pixel. A JSON-LD block with a plain `id` no longer sends a document off the kept road.
- **mupdf is an optional peer.** This package is MIT and an install brought mupdf, under the AGPL-3.0, though only `--check` loads it. `--check` without it refuses before the run, naming the package, its licence and the command, and `scripts/release.sh` refuses a release whose production dependencies name an AGPL licence.
- **Caster's deferrals are said on the command line** (codeberg.org/BelType/cli issue 1). After the run, `beltype print` prints one line on stderr for each feature Caster drew differently or not at all, naming the element, the feature and what it was painted as (`deferred: div[0]: box-shadow, painted as raster at 300 dpi`); `beltype serve` logs the same lines and answers their count in `x-beltype-deferred`; `print()` returns it as `deferred`. A deferral is reported beside the warnings, not as one: the print still succeeds.
- **The cut waits for the faces an SVG image's text needs.** `beltype print` awaits Caster's `prepare(document).ready` before Cicero cuts, so a face only an SVG `<img>` names is loaded first and embedded (codeberg.org/BelType/caster issue 11). With a Caster that has no `ready`, nothing changes.
- **A JSON-LD data block no longer costs the kept page.** `<script type="application/ld+json">`, with that one attribute, is data the browser never runs, so `beltype serve` leaves it out of the script test, up to its first `</script`.
- **A mail-merge test** (`test/mail-merge.test.ts`): one bill template, twenty customers. prosemirror-stores opens each customer's values and meter readings as the template's graph, its binds compute the days and the consumption, `writeMicrodata` fills the fields, and every bill prints through `beltype serve` on the kept page, each with its own customer and totals and nothing of the bill before it. On the Mac, twenty bills merged and printed in about 1.9 s.

## 0.1.6 — 2026-11-04

- **`beltype serve` keeps one print page.** A document with no script of its own is written into it with `document.open()`, so the realm, Caster's capability registry and the warmed code stay between prints; the previous Cicero client is let go with Cicero 0.1.6's `release()` first. A document that carries a `<script>`, an `<iframe>`, an `<object>`, an `<embed>`, a `javascript:` URL or an `on…=` attribute takes a fresh page, since the `Window` outlives `document.open()` and a script could watch the next client's document. A failed print discards the kept page. Measured on the Mac, medians of 20 warm prints of the paper: 570 ms to 271 ms. Every kept print is byte-identical to the same document printed alone (`test/serve.test.ts`).
- **The log line says where each print's time went**: the road (kept or fresh), the page, the load, the cut, the print, the close, and Caster's stages.
- **Cicero 0.1.6.** Caster 0.1.6 and common 0.1.2 are unchanged.

## 0.1.5 — 2026-11-03

- **`beltype serve`**, `beltype print` behind an HTTP door in Gotenberg's shape: `POST /print` (`multipart/form-data`, `index.html` and the files beside it, flags as plain fields) answers the PDF, and `GET /health` the server's state. One Chromium stays warm, and forme, Caster's Rust writer, stays warm in a shared worker that every document's page hands its display list to. Under forme the sample paper prints in 533 ms against `beltype print`'s 753, its write in about 50 ms against 133. One print runs at a time; the browser restarts after a crash, after `--restart-after` prints, and after a print over `--timeout`. It binds `127.0.0.1` and fetches nothing from a network. The warm-up document ships one font, Source Sans 3 (SIL OFL), in `assets/warmup/`.
- **Caster 0.1.6**, which carries forme behind `writer: 'forme'` and the shared worker the server keeps warm. Cicero 0.1.5 and common 0.1.2 are unchanged.
- **The print's steps leave `print()`** for `src/run.ts` (`documentAssets`, `servedHtml`, `routeCompanions`, `routeDocument`, `printOnPage`), so a server can share them; `print()` behaves, says and traces as before. The document's own files are answered on the page, the companions' and the refusals on the context.
- **`SOURCE_DATE_EPOCH`** sets the file's creation and modification dates, so the same document prints to the same bytes twice.

## 0.1.4 — 2026-11-03

- **Caster 0.1.5, Cicero 0.1.5 and common 0.1.2**, the first versions that carry the flags in one shape and the engine's own subpaths.
- **Flags in one shape.** `--flag <owner>.<name>=<value>`, repeatable, sets a row of Caster's, Cicero's or the command line's own table, each declared with `@beltype/common/flags`. `--printer` and `--check` are the command line's rows spelled plainly. `beltype print --help` lists every table. Every default reproduces today's behaviour.
- **`--printer chromium`.** Chromium's own print (`page.pdf()`) prints the pages Cicero presented, one sheet to a page; it refuses when the pages are not all one size. Caster stays the default. This reverses the earlier "one road" rule, at Egildo's request of 2026-10-30.
- **`--trace <file.json>`.** Where a run's time went: node's clock around each step, Cicero's `performance.measure` entries, Caster's report timings, the versions and the resolved flags. Written even when the run refuses.
- **`--check`.** Screenshots each presented page, rasterises the PDF at 96 dpi and diffs the pairs into `<name>.check/`. It reports and never fails.
- **The trace gains `caster.fonts`**, the per-instance milliseconds of Caster's report.
- **`mupdf` 1.28.1 is a dependency**, loaded only under `--check`. The import map the page gets now maps `@beltype/common/flags`, which Caster 0.1.4 imports. Needs `@beltype/common` 0.1.2, `@beltype/caster` 0.1.4 and `@beltype/cicero` 0.1.5.
- **Node's compile cache is on.** `cli.ts` is now a stub that calls `module.enableCompileCache()` and imports `main.ts`, where the command lives. A warm run of the sample paper saves about 35 ms of the 280 ms Node spends before `print()` starts. The cache is Node's own, in the temporary directory (`node-compile-cache`), about 2 MB.
- **A plain print does not load Caster's flag table in Node.** `flags.ts` imports each package's table when it is needed: `--flag caster.*`, `--help`, and the trace's `flags` field (loaded after the total is taken, so the trace does not count it). Caster resolves its own defaults in the page. About 30 ms off a warm print of the sample paper. Cicero's table is still loaded, because the run needs Cicero's engine in Node anyway.
